# Как добавить сценку со снегирём

Все сценки лежат в `app/var/www/YT/js/eggs.js`. Это методы объекта `effects` внутри `runConfetti()`. Файл грузится по требованию при первом салюте (`loadEggs()` в `youtubedlwebui.js`). Как устроен движок, описано в [07-pashalki.md](../explanation/07-pashalki.md).

## 1. Придумать раскадровку

Опишите сценку тремя-пятью событиями и проставьте каждому кадр: `const LAND = 60, KICK = 272`. Вся сценка укладывается в 360-450 кадров при 60 fps.

## 2. Нарисовать спрайты

Спрайт - это массив строк, один символ на пиксель, `.` означает прозрачный пиксель. Объявите его рядом с остальными `PIX_*`, перед `PIX_SWEAT`. Обёртку объявите рядом с `mugSprite`:

```js
const panSprite = () => cachedPixelSprite('pan', ...PIX_PAN);
```

Накладку на снегиря (шапку, маску) рисуйте на сетке 18x16, как у самого спрайта: тогда она ляжет точно на голову.

## 3. Расставить по геометрии

| Что | Значение |
|---|---|
| Пиксель снегиря | `c = birdCell` |
| Полуширина снегиря | `size = 9c` (спрайт 18x16 клеток) |
| Где стоит снегирь | `birdY` |
| Земля | `birdY + 8c` |
| Клюв | `(±8.5c, -3.5c)` от центра |
| Два снегиря вплотную | `size * 2 + c` |
| Сторона | `f = ±1`, случайно; позиции считайте через `f` |

Все размеры берите от `c` и проверяйте на ширине 375: координаты по x ограничивайте через `Math.min` и `Math.max`.

## 4. Собрать сценку из помощников

- `snegir(path, frames, pose, facing)` - снегирь.
  - `path(t)` возвращает `[x, y, 0]`.
  - `pose(t)`: 0 - клюв закрыт, 1 - открыт, 2 - зажмурен, 3 - лапа вперёд, 4 - фейспалм, 5 - дзен.
  - `facing`: 1 или -1, можно функцией от `t`.
- `birdRise(t, frames)` - выход снизу и уход вниз. Прибавляйте к нему свои смещения по y.
- `scene(frames, t => ...)` - всё, что рисуется само: земля, вода, предметы. Внутри доступны `cellAt`, `pixLine` и `blit(img, x, y, dir, scale)`.
- `overlay(img, path, frames, facing)` - шапка или маска поверх снегиря.
- `popSprite`, `pixelBurst`, `pixelPuff`, `screenTint` - реплики, брызги, дым, вспышка экрана.
- Предмет со своей траекторией: `spawn(..., { shape: 'sprite', props: () => pixImg(img, { ...still, path, imgAt }) })`.

## 5. Соблюсти порядок отрисовки

Что заспавнено раньше, то рисуется ниже. Сугроб, который должен закрыть снегиря, спавните после снегиря. Кабель за птицей спавните до неё.

## 6. Учесть ловушки

- Сцену спавните только в `at(0, 0)`: координаты сцены отсчитываются от позиции частицы.
- Белое на кремовом фоне не видно. Давайте контур или тень.
- Крупное закрашивайте сплошными `fillRect`, а не клетками: на дробном dpr между клетками просвечивает фон.
- Мелкое рядом со снегирём теряется. Блоки делайте не меньше 2-3c.

## 7. Зарегистрировать

Добавьте `['birdName', 4]` в `CONFETTI_VOLLEYS`. Без строки в этом списке сценка не выпадет никогда.

## 8. Собрать

```bash
node --check app/var/www/YT/js/eggs.js
```

```bash
./minify_js.sh
```

В HTML подключён `.min.js`, поэтому без минификации правка не появится. Dev-страница после пересборки перезагружается сама.

## 9. Проверить на dev

Подмените выбор залпа в консоли и запустите сценку:

```js
pickConfettiVolley = () => ({ kind: 'birdName', palette: CONFETTI_COLORS }); fireConfetti();
```

Для покадровой проверки подмените `requestAnimationFrame` очередью и подавайте фиктивное время с шагом +16.67 мс: движок считает жизнь частиц по таймстампам. Прогоните сценку до конца (пока `confettiRun` не станет `null`), чтобы убедиться, что нет ошибок. Потом снимите несколько ключевых кадров на 1280x720 и на 375x700.

## 10. Описать

- Добавьте строку в пункт «Сценки со снегирём» в `docs/explanation/07-pashalki.md`.
- Допишите название в шапку комментария `fireConfetti`.
