# Структура проекта

```
YT/
├── app/
│   ├── start.sh                 точка входа контейнера
│   ├── logger.sh                генерирует Python-плагин логирования yt-dlp
│   ├── mux_translated.sh        вклеивает переведённую vot-cli дорожку в видео через ffmpeg
│   ├── etc/
│   │   ├── nginx/                конфиг веб-сервера
│   │   ├── yt-dlp.conf            общий конфиг yt-dlp (лимиты, фильтр 18+)
│   │   ├── cron/                  пример хостового crontab
│   │   └── Scripts/                скрипты очистки старых файлов и обновления yt-dlp
│   ├── patches/                  патч для yt-dlp (мягкая очистка имён файлов)
│   └── var/www/YT/               сама веб-папка приложения
│       ├── index.php              точка входа, обработка запросов
│       ├── error_pages.php        страница ошибки CSRF
│       ├── health.php             лёгкий эндпоинт для Docker HEALTHCHECK
│       ├── manifest.json          PWA-манифест (иконка, имя, share_target для "Поделиться")
│       ├── static_version         хэш содержимого CSS/JS, создаётся при сборке образа
│       ├── 404.html               пасхалка "живые глаза" на странице 404
│       ├── 500.html               пасхалка "гиперпространство" на странице 500
│       ├── class/
│       │   ├── Downloader.php     запуск и управление загрузками
│       │   ├── FileHandler.php    работа с файлами на диске
│       │   ├── PlaylistProbe.php  разбор содержимого плейлиста для окна выбора
│       │   ├── Feedback.php       хранилище доски обратной связи
│       │   ├── Markdown.php       безопасный рендер разметки сообщений
│       │   └── ProxyStatus.php    замер живости SOCKS5-прокси
│       ├── config/
│       │   ├── config.php          настройки сайта
│       │   └── favicon_domains.json список сайтов для подсказки иконок
│       ├── views/                  HTML-шаблоны страницы
│       ├── js/                     фронтенд-логика
│       ├── css/                    стили оформления
│       ├── img/                    маскот, иконки, картинки интерфейса
│       ├── favicons/               кешированные иконки известных сайтов
│       ├── download/               сюда сохраняются скачанные файлы
│       └── tmp/                    логи, очередь загрузок, кэш разбора плейлистов
├── Dockerfile
├── docker-compose.yml
├── patch_replace_insane.sh       переналагает патч yt-dlp вручную, без пересборки образа
├── load_favicons.py              скачивает иконки сайтов в favicons/
└── .env.example
```

Каталог доски обратной связи в дерево не входит: он лежит **выше** корня сайта, по умолчанию `/var/www/YT_data/feedback`, и внутри веб-папки его нет намеренно.

```
/var/www/YT_data/feedback/
├── d/000123.json    один диалог - один файл
├── counter          выдача номеров обращений
├── stats.json       готовые числа для значка в подвале
└── rl/              отметки лимитов частоты (HMAC от адреса, не сам адрес)
```

## Скрипты и их назначение

| Скрипт | Когда запускается | Что делает |
|---|---|---|
| `app/start.sh` | старт контейнера | сохраняет версию yt-dlp, поднимает сервер PO-токенов (bgutil), php-fpm, выводит логи yt-dlp и обратной связи в `docker logs`, запускает nginx |
| `app/logger.sh` | сборка образа | генерирует Python-постпроцессор логирования для yt-dlp |
| `app/etc/Scripts/cleanup.sh` | вручную | удаляет всё из `download/` и `tmp/` |
| `app/etc/Scripts/2hourcleanup.sh` | хостовый cron, каждые 15 минут | удаляет файлы старше `retentionMinutes` |
| `app/etc/Scripts/update-ytdlp.sh` | хостовый cron, раз в сутки | обновляет yt-dlp и переналагает патч имён файлов |
| `app/etc/Scripts/ensure_mp4.sh` | сама задача, после загрузки видео | проверяет контейнер и кодеки готового файла, приводит к воспроизводимому mp4 |
| `patch_replace_insane.sh` | вручную | переналагает патч мягкой очистки имён файлов без пересборки образа |
| `load_favicons.py` | вручную, при добавлении новых сайтов | скачивает недостающие иконки сайтов в `favicons/` |
